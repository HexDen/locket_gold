# 👑 HexDen Locket AI Filter Server

Máy chủ xử lý bộ lọc ảnh AI và hiệu ứng **"Đang Rửa Ảnh"** miễn phí cho dự án **Locket Gold VIP - HexDen**.

## Tính năng:
- 🎞️ **Vintage Film:** Hiệu ứng máy phim analog, Polaroid, hạt bụi grain và ánh sáng lóa hoài cổ.
- 🌸 **Anime Art:** Tông màu hoạt hình Ghibli sắc nét và rực rỡ.
- ⚡ **Cyber HexDen:** Màu xanh Cyan / Neon độc quyền thương hiệu HexDen.

## Cách dùng với Shadowrocket:
Gửi ảnh qua phương thức `POST /process?filter=vintage_film` (Body dạng binary JPEG).
